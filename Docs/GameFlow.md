# 한 판 종료와 재시작

## 범위와 책임

- `GameManager`: 저주 단지 개수, 출구 해금, 승리/패배 상태를 판정한다. `OnStateChanged`는 Playing/Victory/Defeat 전환을 알린다. 기존 `onVictory`/`onDefeat` UnityEvent 연결도 유지한다.
- `GameSessionController`: 결과 패널, 시간/커서, 진행 중 행동 취소, 재시작/종료 버튼을 관리한다. MainScene의 GameManager 오브젝트에 연결했다.
- `GameplayInput.IsBlocked`: 기존 전체 지도 입력 차단과 게임 상태(Playing 이외)를 함께 확인한다. 이동·시점·상호작용·핫바가 이 경계를 사용한다.

현재는 MainScene 진입 즉시 플레이한다. 타이틀/시작 메뉴와 별도 ESC 일시정지 메뉴는 이번 구현에 포함하지 않는다.

## 종료 순서

저주 단지 조건 충족 후 출구 진입은 승리, 체력 소진 또는 미라화 완료는 패배다. 상태가 확정되면:

1. 해당 결과 패널을 표시하고 결과 레이어를 Canvas의 앞으로 이동한다.
2. 전체 지도를 닫아 맵 일시정지/커서 복원을 끝낸다. 퀴즈 UI도 숨긴다.
3. 사용 중인 소모품을 소비 없이 취소하고, 미라의 예약 공격·이동 경로를 취소한 뒤 정지한다.
4. 시간 배율을 0으로 하고 커서를 표시/해제한다.
5. 재시작·종료 버튼을 활성화한다. UI는 시간 배율 0에서도 동작한다.

맵이 열린 채 종료되어도 맵 닫기가 게임을 다시 진행시키지 않는다. 종료 후 지도 재열기·아이템 사용·상자/단지 획득·추가 피해는 차단한다. 미라의 타격 시점에도 Playing 상태를 확인한다.

## 재시작의 의미

`GameSessionController.RestartGame()`은 현재 씬을 `LoadSceneAsync(..., Single)`로 다시 읽는다. 중복 요청을 막고 로딩 중 버튼을 비활성화한다. 로딩 시작 실패 시 결과 화면과 정지 상태를 복원한다.

GameManager는 더 이상 `DontDestroyOnLoad`가 아니다. 플레이어 스포너·설정·결과 패널 참조가 씬에 속하므로 매 판 씬과 함께 새로 만든다. 파괴 시 본인일 때만 싱글톤 참조를 비운다.

재시작하면 새 플레이어, 체력·스태미나·미라화·아이템·단지 개수, 지도 탐험, 맵 콘텐츠와 미로 변화 타이머가 씬/프리팹 초기값에서 다시 시작한다. 설정이 랜덤 시드이면 새 미로를 만든다. `MazeTestBootstrapper.RebuildMaze()`와 달리 **한 판 전체를 새로 시작**하는 기능이다.

`GameManager.StartGame()`은 규칙 상태 초기화이므로 재시작 버튼에 직접 연결하지 않는다. 새 타이틀 씬을 추가할 경우에도 씬 전용 GameManager를 영속화하지 않는다.

## 결과 UI

기존 victoryPanel/defeatPanel 이미지와 UnityEvent 연결은 유지한다. MainScene에서 버튼을 지정하지 않으면 `ResultActions`에 '다시 시작'/'게임 종료' 기본 uGUI 버튼을 런타임 생성한다. 기존 Pretendard 폰트를 사용한다.

UI 담당이 직접 제작한 버튼으로 바꾸려면 `GameSessionController`에 Restart Button / Quit Button을 모두 연결한다. 두 결과에서 쓸 수 있도록 두 패널과 형제인 공용 영역에 배치한다. 컨트롤러는 결과 패널 표시, 버튼 이벤트와 interactable 상태를 관리하며, 커스텀 버튼 루트의 표시/숨김은 제작 UI에서 별도로 연결한다. 디자인/애니메이션은 별도 작업이다.

종료 버튼은 빌드에서는 `Application.Quit()`, Editor에서는 Play Mode 정지를 요청한다. 이 동작은 실제 앱을 닫으므로 자동 재시작 검사에서 실행하지 않는다.

## 검증과 남은 범위

`Assets/Editor/GameFlowSmokeCheck.cs`가 MainScene의 실제 플레이 상태에서 다음을 검사한다.

- 단지 수집 전 탈출 거절, 수집 후 해금, 실제 출구 트리거 승리.
- 지도 열린 상태의 승리, 시간/커서 소유권 전환, 종료 후 조작·추가 피해·상자 획득·소모품 사용 차단.
- 진행 중 소모품 취소와 미소비, 미라 즉시 정지.
- 체력 소진과 미라화 패배, 올바른 결과 패널과 버튼 활성화.
- UI 프레임 이후 버튼의 최상단 Raycast 판정과 PointerClick 처리, 네 번의 연속 씬 재시작.
- 재시작 후 단일 매니저, 새 진행도·체력·미라화·빈 핫바·시작 좌표·시간 복원.

시각적 완성도, 직접 키보드/마우스 조작, 장시간 추적, 빌드의 종료 동작, 실패한 씬 로딩 복원 분기의 실제 실행은 별도 확인 대상이다. 헤드리스 검사를 전체 게임 QA 완료로 보지 않는다.
