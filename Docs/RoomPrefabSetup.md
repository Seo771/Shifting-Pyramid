# 3x3 방 프리팹 연결하기

보물방·특수방은 각각 3x3 영역을 차지하는 프리팹 하나다.
현재 구현은 **표시한 출입구를 전부 연결**하고, 방 내부는 서로 이동 가능한 공간이라고 가정한다.
문 애니메이션·잠금 처리와 내부 구획의 별도 경로 계산은 포함하지 않는다.

## 1. 방 루트

- 방 루트에 `MazeRoomView`를 붙인다.
- 원본 프리팹 루트 피벗은 방 중앙 바닥, 회전은 `(0,0,0)`, 스케일은 `(1,1,1)`로 맞춘다. 생성 시 배치된 인스턴스만 0°/90°/180°/270°로 회전한다.
- `Authored Tile Size`를 미로 렌더러의 `Tile Size`와 맞춘다. 현재는 10이며 방 크기는 30x30이다.
- 일반 타일 9개를 재료로 사용했다면 모든 `MazeTileView`를 제거하고 내부 벽·중복 콜라이더를 정리한다.
- 보물 획득에는 방 안의 보물 오브젝트에 기존 `Treasure` 컴포넌트를 사용한다.

## 2. 문 표시점

문마다 빈 자식 오브젝트를 하나 만들고 `MazeRoomEntranceMarker`를 붙인다.
좌표는 방 남서쪽 칸 `(0,0)`부터 북동쪽 칸 `(2,2)`까지 사용한다.

| 문 위치 | Local Cell | Direction | 방 루트 기준 표시점 X/Z (타일 간격 10) |
| --- | --- | --- | --- |
| 북쪽 중앙 | (1,2) | North | (0,15) |
| 동쪽 중앙 | (2,1) | East | (15,0) |
| 남쪽 중앙 | (1,0) | South | (0,-15) |
| 서쪽 중앙 | (0,1) | West | (-15,0) |

가운데가 아닌 경계 칸에도 문을 만들 수 있다. 예를 들어 북서쪽 칸의 북쪽 문은 `(0,2), North`다.
컴포넌트 메뉴의 **Align Marker To Grid**로 표시점을 지정한 경계에 맞출 수 있다.
이 기능은 표시점만 이동한다. 실제 문 구멍과 콜라이더도 같은 위치에 맞춰야 한다.
Y 위치는 문 높이에 맞춰도 되며, 생성기는 X/Z 위치를 검사한다.

`MazeRoomView`는 하위 표시점을 자동 수집한다. 출입구가 없거나, 중복되거나, 바깥을 향하지 않거나, 격자 경계에서 벗어나면 생성 전에 오류를 출력한다.
방 내부의 표시되지 않은 문/구멍을 자동으로 감지하지는 않으므로 모든 실제 출입구에 표시점을 붙인다.
표시점 좌표와 방향은 원본 프리팹 기준으로 한 번만 설정한다. 배치된 방의 회전과 함께 논리 출입구 및 실제 프리팹이 같은 방향으로 회전한다.

## 3. 설정 에셋

`Assets/Data/MazeBalanceSettings.asset`에서 다음을 연결한다.

- `Treasure Room 3x3 Prefab`: 보물방 루트의 `MazeRoomView`.
- `Special Room 3x3 Prefabs`: 특수방 루트의 `MazeRoomView` 목록.
- `Exit Room Prefab`: 기존 1칸 출구 프리팹의 `MazeTileView`.

기존 1칸 보물방/특수방 참조는 직렬화 데이터를 보존하기 위해 숨겨 두었으며 새 생성에는 사용하지 않는다.
프리팹이 준비되지 않은 종류는 해당 방 개수를 0으로 설정한다. 개수가 양수인데 프리팹이 비어 있으면 일반 타일로 대체하지 않고 설정 오류를 표시한다.

기본 에셋은 15x15, 보물방 5개, 특수방 2개다. 방끼리 최소 한 칸을 띄우고 맵 가장자리를 통로로 남긴다.
배치 공간이 부족하면 최대 128번 재시도한 뒤 크기/개수 조정을 안내하며, 기존 표시된 미로를 유지한다.

## 4. 씬 실행

`MainScene` 또는 `Maze_TestScene`의 `MazeTestBootstrapper`에 설정 에셋과 `MazeRenderer`가 연결되어 있는지 확인한다.
`MazeRenderer.Tile Prefab`은 기존 일반 타일로 유지한다.
씬의 `PlayerMazeSpawner`는 생성 후 자동으로 찾을 수 있으며, 플레이어는 시작 칸 `(0,0)`에 배치된다.

생성은 방 위치·회전 예약 → 방 단위 DFS → 회전된 모든 문 연결 → 출구 배치 → BFS 검증 → 렌더링 순서다.
일반 타일은 방 영역 밖에만 생성되고, 방은 중앙에 프리팹 하나만 생성된다.
보물방과 특수방의 9칸 모두 보호 플래그를 갖는다. 런타임 일반 통로 변경은 격자 로직까지 구현했으며, 씬에서 주기적으로 실행하고 화면에 반영하는 연결은 아직 없다. 특수방의 동적 교체도 아직 구현하지 않았다.

## 검증 실행

Unity 없이 계산 코드의 회귀 검사를 실행할 수 있다(.NET 10 SDK 필요).

```powershell
dotnet run --project Tests/MazeCoreChecks/MazeCoreChecks.csproj
```

250개 Seed에서 전체 도달성, 방 점유/보호, 출입구 제한, 공유 벽 일치, 결정적 생성 등을 검사한다.
실제 프리팹의 벽/콜라이더, 문 애니메이션과 플레이어 이동은 Unity Play Mode에서 확인한다.
